# CLAUDE.md

This file provides guidance for learning Biblical Hebrew from scratch, with practical connections to the Strong's Number Embedding Project.

## Learning Goal

Learn Biblical Hebrew (עברית מקראית) to read the Masoretic Text (馬索拉譯本) of the Old Testament, leveraging existing work with Strong's Numbers and UNV parsing.

## Reading Direction

Hebrew reads **right to left** (→←):

```
בְּרֵאשִׁ֖ית בָּרָ֣א אֱלֹהִ֑ים אֵ֥ת הַשָּׁמַ֖יִם וְאֵ֥ת הָאָֽרֶץ׃
```
Start from בְּרֵאשִׁית (right) and read toward הָאָרֶץ (left).

## Connection to Folk Songs

**Mayim Mayim (מים מים)**:
- מַיִם = H4325 (water) — same word as Gen 1:2
- Based on Isaiah 12:3: וּשְׁאַבְתֶּם־מַיִם בְּשָׂשׂוֹן

**Hava Nagila (הבה נגילה)**:
- הָבָה = "let us" (cohortative)
- נָגִיל = "rejoice" from H1523 גִּיל
- שִׂמְחָה = H8057 (joy)

## Alphabet Cards Application

Interactive flashcard app for learning the 22 Hebrew letters.

**How to Run**:
```bash
open alphabet_cards/index.html
```

### Features

| Feature | Description |
|---------|-------------|
| Overview Grid | 22 letters with [F] final form / [V] vowel indicators |
| Letter Cards | Large letter, name, pronunciation, 5 example words |
| Stroke Animation | Pen path tracing showing traditional writing order |
| Audio | Web Speech API pronunciation |
| Form Switching | Toggle between base / final / vowel forms |
| Print Mode | Single large letter display for printing |

### Keyboard Shortcuts

| Key | Function |
|-----|----------|
| `←` `→` | Previous / Next letter |
| `↑` | Return to overview |
| `Space` | Base form |
| `F` | Final form (字尾形) |
| `V` | Vowel form (母音形) |
| `P` | Print mode |
| `S` | Play stroke animation |
| `A` | Play audio |
| `ESC` | Go back |

### Example Word Format

Each letter has 5 example words displaying:
- Hebrew word (target letter highlighted in red)
- Strong's Number (e.g., H7965)
- Transliteration (e.g., "shalom")
- English translation
- Chinese translation

### Special Forms

**Final Forms (字尾形)** - 5 letters change shape at word end:
- כ → ך (Kaf)
- מ → ם (Mem)
- נ → ן (Nun)
- פ → ף (Pe)
- צ → ץ (Tsade)

**Vowel Letters (母音字母)** - Matres lectionis:
- א (Aleph) - can represent ā
- ה (He) - can represent ā, ē at word end
- ו (Vav) - represents ō (cholam) or ū (shureq)
- י (Yod) - represents ī
