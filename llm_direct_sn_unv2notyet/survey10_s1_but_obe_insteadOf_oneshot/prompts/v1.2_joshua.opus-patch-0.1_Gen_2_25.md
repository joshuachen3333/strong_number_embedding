## ROOT CAUSE ANALYSIS

I produced four different outputs because one Strong's Number group — `<01961><8799>` (Hebrew היה, "to be/were") — had **no lexical anchor in the target Chinese sentence**, and I had no rule for what to do when that happens. So each pass I re-guessed.

The structural trap: in the UNV source, `<01961><8799>` was carried by `當時` ("at that time"), a word the revised target text deletes. When I strip the shell and try to re-place the bare verb, the word it used to live on is gone. Hebrew **requires** an explicit finite copula ("they *were* naked"); natural Chinese expresses the same state with a bare stative predicate ("都赤身裸體") and needs **no copula word at all**. The SN therefore has a real source-side referent but no surface target token to attach to — an "orphan."

Faced with an orphan and no decision rule, I let *local plausibility* drive each pass, and every candidate had a different surface-level temptation:

- **R2c → `那人<0120>`**: Hebrew word order fronts the verbal state before the subject, so the verb "felt" like it belonged near the clause head.
- **R2b/R2d → `都<08147>`**: "both *were*" is conceptually adjacent, so the quantifier looked like a host.
- **R2a → after `赤身裸體<06174>`**: I correctly found the predicate but then defaulted to source SN *array order* (`<06174>` then the trailing verb) instead of semantic order.

None of these is anchored to a stable principle, so nothing pinned the choice — I oscillated between four equally "defensible" guesses. The deeper failure was **mixing two incompatible ordering authorities**: sometimes I ordered by Hebrew word order, sometimes by the source SN sequence, sometimes by Chinese surface adjacency. With three competing criteria and an orphaned token, convergence was impossible. The cure is a single deterministic rule for orphans, not better intuition.

## INSTRUCTIONS — Strong's Number Placement (complete replacement)

### 1. Core task
Place each bare Strong's Number onto the Chinese token that carries its **meaning**, preserving every SN from the source exactly once. You are projecting semantics, not copying source word order.

### 2. Classify every SN before placing it
For each SN (or fused SN pair like a verb + its `<8xxx>` morphology tag), decide:

- **(A) Anchored** — a Chinese word directly translates it → attach to that word.
- **(B) Orphan** — the source word it represents has **no distinct Chinese equivalent** in the target sentence. This is almost always: copulas/existence verbs (`<01961>` היה "to be/were/was"), and other function words the target language drops (`當時`, particles, some prepositions).

Treat `<01961>` and any "to be / there was / were" verb as an orphan **by default** unless the Chinese contains an explicit `是 / 有 / 成為 / 當…時`.

### 3. THE ORPHAN RULE (this is what stops the oscillation)
When an SN is an orphan, do **all** of the following — no judgment, no per-verse re-guessing:

1. **Find the predicate that expresses the resulting state.** The orphaned copular/stative verb belongs to the *predicate*, never to the subject and never to a quantifier. Identify the Chinese word group that conveys the state the verb asserts (here: 赤身裸體, "were naked").
2. **NEVER attach an orphan copula to:**
   - the subject (`那人<0120>`) — "were" is not a property of the man;
   - a quantifier/number (`都<08147>`) — "both" maps to the *count* word, not to the verbal state;
   - the start of the clause just because Hebrew fronts the verb. **Hebrew word order is not a placement authority.**
3. **Order inside the predicate group by source-side grammatical role, verbal-before-adjectival.** The copula `<01961><8799>` describes the state; the adjective/stative noun `<06174>` *is* the state. The verb introduces the adjective, so it comes **immediately before** the adjective's SN:

   ```
   赤身裸體<01961><8799><06174>
   ```

   Do **not** place it after the adjective SN (`赤身裸體<06174><01961><8799>` is wrong — that orders by raw SN-array position, not by meaning).

### 4. Single ordering authority (kill the three-way conflict)
When multiple SNs land on or beside the same Chinese predicate, order them by **semantic role within the predicate**, in this fixed precedence:

> copular/existence verb → stative adjective/predicate noun → modifiers

Never order by (a) Hebrew word order, (b) the raw left-to-right sequence of bare numbers in the source array, or (c) Chinese surface adjacency. Those three criteria are the source of oscillation; the role-based order above overrides all of them.
