圖 2 ─ R2 收斂與觸發機制 (Convergence & Triggers)

每個模型獨立做收斂測試，再根據穩定度分級觸發不同路徑。

flowchart LR
    subgraph CONV["收斂測試 (每模型獨立)"]
        direction TB
        R1O["R1 輸出"]
        R2A["R2a: 盲目重做"]

        CMP2{"R2b == R2a?"}
        R2C["R2c-R2e: 繼續..."]

        R1O --> R2A --> CMP1

        CMP1 -- "❌" --> R2B --> CMP2
        CMP2 -- "✅" --> EASY2["Level 0: Easy\n(stable at R2a)"]
        CMP2 -- "❌" --> R2C --> CMP3
        CMP3 -- "✅ at R2b" --> MILD["Level 1: Mild"]
        CMP3 -- "✅ at R2c-d" --> MOD["Level 2: Moderate"]

圖 3 ─ Trigger 2 詳細流程 (Model Patch Generation)

距離 ≥ 2.0 時觸發：驗證 → 反饋 → 自寫 Patch → 回測。

flowchart TB
    START["Trigger 2 觸發\n兩模型一致, 第三者偏離\ndistance ≥ 2.0"]

    D3{"distance ≥ 3.0?"}

    VAL["驗證輪:\n問弱模型是否同意\n兩者的輸出"]
    VAGREE{"弱模型同意?"}

    FB["反饋輪 (2-step)"]

    subgraph FEEDBACK["Step 1: 穩定模型給反饋"]
        F1["穩定模型 A\n指出弱模型錯誤"]
        F2["穩定模型 B\n指出弱模型錯誤"]
    end

    subgraph SELFPATCH["Step 2: 弱模型自寫 Patch"]
        SP["讀取兩份反饋\n+ 現有 patch (若有)\n→ 撰寫統一 patch"]
    end

    subgraph REGTEST["回測 (Regression)"]
        SAMPLE["取樣過去經文\nMild 10% / Mod 20% / Strong 30%"]
        RUN["用新 patch 重跑"]
        CHECK{"穩定度 ≥ 舊?"}
    end

    SAVE["✅ 保存 patch\n用兩者輸出作 Gold Standard\nresolved_at: r2_model_patch"]
    REVERT["❌ Revert patch\n降級為正常 R2 辯論"]

    START --> D3
    D3 -- "≥ 3.0: 直接跳過驗證" --> FB
    D3 -- "< 3.0" --> VAL
    VAL --> VAGREE
    VAGREE -- "✅ 同意" --> FB
    VAGREE -- "❌ 不同意" --> REVERT

    FB --> F1 & F2
    F1 & F2 --> SP

    SP --> SAMPLE --> RUN --> CHECK
    CHECK -- "✅ 通過" --> SAVE
    CHECK -- "❌ 回歸" --> REVERT

圖 4 ─ Prompt 自動演化流程 (Auto-Evolution)

由 Trigger 1 或 R3 all_wrong 觸發。三模型起草 → 投票 → 回測 → 採用。

    TRIG["觸發源\nTrigger 1 (avg≥2.0)\n或 R3 all_wrong"]

    subgraph DRAFT["Phase 1: 起草新 Prompt"]

        D2["gemini 起草"]

    subgraph VOTE["Phase 2: 投票"]
        V1["opus 評三份草案"]
        V2["gemini 評三份草案"]
        V3["gpt 評三份草案"]
        TALLY{"2/3 多數決?"}
    end

    subgraph REGRESS["Phase 3: 回測"]
        SAMPLE["取樣過去 Gold Standard"]
        RERUN["用新 Prompt 重跑"]
        CMP{"品質 ≥ 舊 Prompt?"}
    end

    ADOPT["✅ 採用新 Prompt\nv1.x → v1.(x+1)\n儲存至 prompts/"]

    TALLY -- "✅ 勝出" --> SAMPLE --> RERUN --> CMP
    TALLY -- "❌ 無共識" --> REJECT

    CMP -- "✅ 通過" --> ADOPT
