## API 使用說明

### FHL Bible API Endpoint

**Base URL**: `https://bible.fhl.net/json/qb.php`

**必要參數**:
- `version` - 聖經版本代碼 (unv, kjv, esv, rcuv2010, lcc, etc.)
- `chineses` - **中文書卷縮寫** (見上表 "Chinese" 欄位)
- `chap` - 章節號碼
- `strong` - Strong's Numbers 開關 (1=開啟, 0=關閉)

**重要提示**:
- ⚠️ **即使查詢英文版本聖經，也必須使用中文書卷縮寫** (`chineses` 參數)
- 本項目的 FHL API 端點不使用 `engs` 參數

## API 調用範例

### 舊約範例

```bash
# 創世記第1章 (KJV with Strong's Numbers)
https://bible.fhl.net/json/qb.php?version=kjv&chineses=創&chap=1&strong=1

# 詩篇第23篇 (和合本 UNV with Strong's)
https://bible.fhl.net/json/qb.php?version=unv&chineses=詩&chap=23&strong=1

# 以賽亞書第53章 (ESV without Strong's)
https://bible.fhl.net/json/qb.php?version=esv&chineses=賽&chap=53&strong=0
```

## JavaScript 使用範例

### 從中文縮寫查詢英文名稱

```javascript
const books = [
    { english: "Genesis", chinese: "創" },
    { english: "Exodus", chinese: "出" },
    // ... (完整列表見上方表格)
];

// 查詢函數
function getEnglishName(chineseAbbr) {
    const book = books.find(b => b.chinese === chineseAbbr);
    return book ? book.english : null;
}

// 使用範例
console.log(getEnglishName("創")); // Output: "Genesis"
console.log(getEnglishName("太")); // Output: "Matthew"
```

### 從英文名稱查詢中文縮寫

```javascript
function getChineseAbbr(englishName) {
    const book = books.find(b => b.english === englishName);
    return book ? book.chinese : null;
}

// 使用範例
console.log(getChineseAbbr("Genesis"));   // Output: "創"
console.log(getChineseAbbr("Matthew"));   // Output: "太"
console.log(getChineseAbbr("Revelation")); // Output: "啟"
```

### API 調用封裝函數

```javascript
async function fetchBibleChapter(englishBook, chapter, version = 'kjv', withStrongs = true) {
    const chineseAbbr = getChineseAbbr(englishBook);

    if (!chineseAbbr) {
        throw new Error(`Unknown book: ${englishBook}`);
    }

    const url = `https://bible.fhl.net/json/qb.php?version=${version}&chineses=${chineseAbbr}&chap=${chapter}&strong=${withStrongs ? 1 : 0}`;

    const response = await fetch(url);
    const data = await response.json();

    return data.record; // Returns array of verses
}

// 使用範例
fetchBibleChapter("Genesis", 1, "kjv", true)
    .then(verses => console.log(verses))
    .catch(error => console.error(error));
```

## 支援的聖經版本

根據專案文件，目前支援的版本包括：

- **UNV** (和合本) - Chinese Union Version with Strong's
- **KJV** - King James Version with Strong's
- **ESV** - English Standard Version
- **RCUV2010** (和合本2010) - Revised Chinese Union Version 2010
- **LCC** (呂振中譯本) - Lü Zhènzhōng Translation
- **BHS** - Biblia Hebraica Stuttgartensia (Hebrew OT, via data extraction)
- **FHLWH** - FHL Westcott-Hort Greek NT (via data extraction)
